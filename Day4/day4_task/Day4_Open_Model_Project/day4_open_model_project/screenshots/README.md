# Screenshots

The task requires screenshots of:
1. estimator output
2. context-length runs
3. quantization runs
4. `ollama list`
5. `ollama ps`
6. model-card/licence pages

The first three have text captures generated from the estimator in this project. For the machine-specific and web-page evidence, capture the screenshots on the actual machine/browser and save them here as PNG files. Do not fabricate those screenshots.
